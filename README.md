# CertX

Batch certificate generator. Upload a template image and a CSV of participants, position the text fields with the built-in editor, and generate personalized certificates for everyone. Download them all as a ZIP.

Special thanks to [clerat6667](https://github.com/clerat6667) for the base Python source code that this project was ported from.

> Note: this is a **Node.js** project, not a Python project. The Python source was only used as a starting point.

## Setup

```bash
npm install
npm start
```

Then open http://localhost:3000.
